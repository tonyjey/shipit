# Исходники ассетов

Эта папка **намеренно исключена из импорта Godot** файлом `.gdignore`.
Здесь лежат исходники, а не игровые ресурсы.

- `retro_90s_computer_blender.py` — Blender-скрипт, которым сгенерирована модель ПК.
- `pc_source.fbx` — экспорт из Blender.

В игре используется `res://models/pc.glb` — тот же FBX, сконвертированный
в glTF. Godot читает glTF штатно, а импорт FBX требует внешнего конвертера
FBX2glTF и спотыкается на источниках света внутри файла.

## Если модель изменится

1. Правишь скрипт, прогоняешь в Blender, экспортируешь FBX сюда.
2. Конвертируешь в glTF любым способом (Blender умеет экспортировать `.glb` напрямую —
   это самый простой путь, промежуточный FBX не нужен).
3. Кладёшь результат в `models/pc.glb` поверх старого.
